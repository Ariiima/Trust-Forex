Signal Results and Scalp Methodology

Official record

A signal becomes active only when the official message publishes the instrument, side, entry, original Stop Loss and applicable targets. The original values remain fixed for public measurement even if a User independently manages a live trade differently.

Target by target measurement

Each published target is measured separately against the original Stop Loss under chronological first-touch rules. A higher target implies lower targets already crossed; a target not actually reached does not count. A later return through Entry does not erase a reached target or create an assumed break-even, trailing-stop or risk-free result.

Market closure and ambiguity
